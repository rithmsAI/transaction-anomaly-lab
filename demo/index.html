Evidence, with boundaries.

These are precomputed Python results, not browser-side model inference or a live scoring API. Training uses 6,000 events (seed 42), calibration uses seed 43, and testing uses seed 44. There are 112 labeled synthetic anomalies. Test labels are used only to measure outcomes.

The simulator favors patterns captured by the rules. Unusual does not mean fraudulent; these results do not establish real-world performance. Exploring multiple budgets here is descriptive, not a method for selecting a production threshold using test outcomes.
